# frontend-ui

Minimal shared React primitives used by the learning web app. It currently
exports `Button`, `PageState`, and `ErrorState`; feature-specific task UI stays
inside the app until it has a second real consumer.

See the shared-components lesson in
[`FULLSTACK_TUTORIAL.md`](../../../FULLSTACK_TUTORIAL.md).

## Running unit tests

Run `nx test frontend-ui` to execute the unit tests via [Vitest](https://vitest.dev/).
